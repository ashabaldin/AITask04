# СчетаМагазина

Расширение 1С в формате EDT. HTTP-сервис `objects` описывает, ищет, читает и создаёт справочники и документы действующей конфигурации по метаданным. Прикладные поля счёта, партнёра и поступления в коде не перечисляются.

Контракт объектов: [docs/superpowers/specs/2026-10-25-object-service-design.md](docs/superpowers/specs/2026-10-25-object-service-design.md). Регистры ещё не сделаны: [docs/superpowers/specs/2026-10-29-registers-design.md](docs/superpowers/specs/2026-10-29-registers-design.md), план — [docs/superpowers/plans/2026-10-29-registers.md](docs/superpowers/plans/2026-10-29-registers.md). Смысл ответов сервиса не выводи заново из кода, если он уже записан в спецификации.

## Что это за репозиторий

Проект EDT `AI_IS_04.СчетаМагазина`, природа `V8ExtensionNature`. Базовый проект — `AI_IS_04` (`DT-INF/PROJECT.PMF`); его исходников здесь нет. Платформа и режим совместимости расширения — 8.5.1. Язык модулей — русский. Назначение — дополнение (`AddOn`), безопасный режим — `Checked`. Префикс собственных объектов — `СчетаМагазина`. Имя расширения и корень сервиса `objects` не переименовывать.

Документы в `docs/` перенесены из репозитория выгрузки и всё ещё ссылаются на `src/extensions/СчетаМагазина/.../Ext/Module.bsl`, `src/mcp/onec-objects` и `src/tests`. В этом проекте исходники лежат иначе; MCP-сервера и файлов REST Client здесь нет. Править код по путям из документов нельзя.

## Публикация

Веб-сервер публикации запускается и остаётся в этом процессе:

`C:\Users\psi\aiwsis03\ws\AITask04\start.cmd`

Он слушает `127.0.0.1:54316`. Имя публикации — `AITask04`. HTTP-сервис расширения:

`http://127.0.0.1:54316/AITask04/hs/objects`

Аутентификация Basic, пользователь информационной базы `Администратор`, пароль пустой. Проверка: `GET /types?q=Справочник&limit=1` отвечает `200` и JSON; `GET /register` отвечает `501` с кодом `not_implemented`.

В `C:\Users\psi\aiwsis03\ws\AITask04\1c-54316.vrd` атрибут `base` должен оставаться `/AITask04`, как `Location` в `httpd-54316.conf`. Иначе платформа перенаправляет на другой корень, и Apache отвечает `404`. Повторный запуск при занятом порте не делать. Остановка — завершить процесс `httpd` этой публикации.

## Слои

Общие модули серверные, без вызова сервера, привилегированного режима и внешнего соединения.

| Модуль | Делает | Не делает |
| --- | --- | --- |
| `СчетаМагазинаМетаданные` | точное полное имя типа, схема, операции, описание типа значения | запросы к данным и запись объектов |
| `СчетаМагазинаЗначения` | JSON ↔ значение 1С, формат ошибки `path/message/type` | проверку HTTP и транзакцию |
| `СчетаМагазинаДанные` | поиск, полное чтение, подготовка и заполнение объекта | разбор HTTP и сериализацию ответа |
| модуль HTTP-сервиса | параметры, тело, права, статусы, транзакция создания | сборку текста запроса и знание прикладных реквизитов |

Обработчики сервиса не экспортные. Между модулями ходить только через уже экспортные функции. Новый общий модуль не заводить ради раскладки.

Имя из запроса сначала сверяется с коллекциями метаданных (`РазрешитьТип`). В текст запроса попадают только имена уже проверенных метаданных и проверенный числовой лимит. Значения клиента — параметры. Клиентский текст не выполнять. Чтение данных — `ВЫБРАТЬ РАЗРЕШЕННЫЕ`. Привилегированный режим не включать.

## Маршруты

Относительно корня `objects`. Успешный ответ — JSON UTF-8, `Content-Type: application/json; charset=utf-8`, без BOM.

| Метод | Шаблон | Обработчик | Состояние |
| --- | --- | --- | --- |
| GET | `/types` | `НайтиТипы` | поиск справочников и документов |
| GET | `/type` | `ОписатьТип` | схема типа |
| GET | `/search` | `НайтиОбъекты` | поиск объектов |
| GET | `/object` | `ПрочитатьОбъект` | полное чтение |
| POST | `/object` | `СоздатьОбъект` | создание |
| GET | `/register` | `ОписатьРегистр` | `501 not_implemented` |
| GET | `/register/slice` | `ПолучитьСрезРегистра` | `501 not_implemented` |
| GET | `/register/history` | `ПолучитьИсториюРегистра` | `501 not_implemented` |
| POST | `/register/record` | `ЗаписатьЗначениеРегистра` | `501 not_implemented` |

`/type`, `/search` и `/object` на имя регистра по-прежнему отвечают `unsupported_type`. Регистр в эти маршруты не подмешивать.

Самостоятельные типы сейчас — справочники и документы. Перечисления — варианты значений полей. Группы читаются и выбираются как родитель, но не создаются. Документ пишется `РежимЗаписиДокумента.Запись`, без проведения. Табличная часть `ДополнительныеРеквизиты` читается и закрыта для записи. Общие реквизиты с разделением данных в схему не входят. Изменение, удаление, проведение и автозаполнение вне контракта.

Форма отказа: `{"error":{"code","message","details":[{"path","message"}]}}`. Для неподдерживаемого значения у детали есть `type`. Стек и текст исключения клиенту не отдавать; подробности — в журнал регистрации событием `СчетаМагазина`, без тела запроса и учётных данных. Отсутствие объекта и отказ в чтении конкретной записи на `GET /object` — одинаковый `404`. Для остальных операций нет права — `403`.

Коды: `400` `invalid_json|invalid_parameter|invalid_type|invalid_id|invalid_data`; `415` `unsupported_media_type`; `422` `unsupported_type|unsupported_operation|unsupported_value|validation_failed`; `500` `internal_error`. Неизвестный объект метаданных — `invalid_type`; известный, но неподдерживаемый вид — `unsupported_type`.

Создание: проверить и преобразовать JSON до записи; транзакция начинается до `СоздатьЭлемент` / `СоздатьДокумент`; отказ `ПроверитьЗаполнение` или обработчика записи отменяет транзакцию и даёт `validation_failed`; краткий JSON готов до фиксации. Потеря ответа POST не делает повтор безопасным.

## Правки

- Сохранять поведение спецификации. Список полей счёта, партнёра или товара в сервис не добавлять.
- Неизвестный параметр URL и неизвестное поле JSON отклонять, а не игнорировать.
- Чтение полное: неподдерживаемое фактическое значение — отказ всего запроса с путём поля, а не пропуск или строковое представление.
- `null` — штатное пустое значение типа. Даты без `Z` и смещения, местное время базы. UUID в ответе — нижний регистр, каноническая форма с дефисами.
- Поиск объектов: `ПЕРВЫЕ limit+1`, `hasMore` по лишней строке. Символы шаблона `ПОДОБНО` экранировать через `~`.
- Ссылку из UUID не считать доказательством существования: проверка — `ВЫБРАТЬ РАЗРЕШЕННЫЕ`.
- Комментарии в модулях — только неочевидный инвариант, как уже сделано в коде. Сообщения коммитов — на русском.
- Адрес публикации, имя базы, пользователя и пароль не копировать в код расширения и сообщения коммитов. Способ запуска веб-сервера записан в разделе «Публикация».

Основную конфигурацию это расширение не меняет. Подключённый снаружи MCP 1С не считать базой `AI_IS_04`, пока имя конфигурации и расширение не проверены отдельно.
