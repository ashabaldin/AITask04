# Подключение MCP-сервера к агенту

Локальный сервер подключается записью в конфиге агента: имя сервера и команда, которой
агент запускает собранный сервер. Адрес публикации, пользователь и пароль в запись не
пишутся, если запись идёт в git: сервер берёт их из переменных окружения, а окружение
задаётся вне репозитория. Сверено 27.10.2026 по `--help` агентов.

| Агент | Где запись | Как добавить |
| --- | --- | --- |
| Cursor и `cursor-agent` | `.cursor/mcp.json` проекта или `~/.cursor/mcp.json` | файл руками: `{"mcpServers": {"<имя>": {"command": "node", "args": ["<путь к собранному серверу>"]}}}`; в терминале — `cursor-agent mcp list`, `cursor-agent mcp list-tools <имя>` |
| Claude Code | `.mcp.json` проекта или настройки пользователя | `claude mcp add <имя> -- node <путь к собранному серверу>`; переменные — `-e KEY=value` |
| Codex CLI | `~/.codex/config.toml` или `.codex/config.toml` доверенного проекта | `codex mcp add <имя> -- node <путь к собранному серверу>`; переменные — `--env KEY=value` |

Остальные агенты — их документация по MCP, раздел про stdio-серверы.

## Проверка

Откройте новую сессию агента: серверы подключаются при её старте. Агент может спросить,
доверяете ли вы серверу проекта, — подтвердите. Спросите, какие инструменты ему доступны
для работы с базой 1С: в ответе должны быть инструменты вашего сервера. Перед вызовом
изменяющего инструмента агент спрашивает подтверждение — прочитайте аргументы.
